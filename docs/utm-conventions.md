# Convención UTM de BEE SMART

Todos los enlaces que lleven tráfico a bee-smart.ai desde una publicación o anuncio deben usar minúsculas, guiones bajos y valores sin datos personales.

| Campo | Uso | Ejemplos |
| --- | --- | --- |
| `utm_source` | Plataforma | `instagram`, `facebook`, `google`, `linkedin`, `tiktok` |
| `utm_medium` | Tipo de tráfico | `paid_social`, `organic_social`, `cpc`, `email`, `whatsapp` |
| `utm_campaign` | Campaña estable | `ia_para_todos_sep_2026`, `empresas_q4_2026` |
| `utm_content` | Pieza o variante | `reel_3_pasos`, `story_fecha_oct_03`, `carrusel_agentes` |
| `utm_term` | Segmento o palabra clave | `pymes_panama`, `curso_ia`, `automatizacion` |

Ejemplo para un anuncio de Meta:

`https://bee-smart.ai/ai-para-todos/?utm_source=instagram&utm_medium=paid_social&utm_campaign=ia_para_todos_sep_2026&utm_content=reel_fecha_oct_03`

Ejemplo para Google Ads:

`https://bee-smart.ai/empresas/?utm_source=google&utm_medium=cpc&utm_campaign=empresas_q4_2026&utm_term=consultoria_ia_panama`

No usar nombres, correos, teléfonos, identificadores de clientes ni respuestas de formularios en parámetros UTM.
